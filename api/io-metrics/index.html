    API Reference — I/O and Metrics¶

    qimp.io.image¶

    qimp.io.image ¶

    Image loading and preparation utilities.

    Reference: docs/tesi.pdf §3.1.6 (image_preparation module)

    load_tiff_16bit ¶

    load_tiff_16bit(path: str | Path) -> np.ndarray

    Load a TIFF file as a numpy array, preserving 16-bit depth if present.

    Returns the raw pixel array (no normalization, no resize).

    image_conv ¶

    image_conv(path: str | Path, *, require_square: bool = True, require_pow2: bool = True) -> np.ndarray

    Open a grayscale image and verify it is square with side a power of two.

    Returns the (H, W) pixel array. Converts to grayscale (L mode) if needed.

    Raises:

    Type Description
    ValueError

    If the image is not square (when require_square) or its side is not a power of two (when require_pow2). These constraints come from the encoding requirements: image side must be 2^n.

    color_image_conv ¶

    color_image_conv(path: str | Path, *, require_square: bool = True, require_pow2: bool = True) -> np.ndarray

    Open an RGB image and verify it is square with side a power of two.

    Alpha channel, if present, is discarded. Returns shape (H, W, 3).

    Green-Purple ratio image, with selectable output range.

    Thin wrapper around :func:qimp.processing.gp_ratio.classical_gp_image that adds the legacy output_format argument the lab pipeline expects.

    Parameters:

    Name Type Description Default
    green ndarray

    Channel arrays with matching shape.

    		 required

    		 required

    		 0.5

    qimp.metrics¶

    qimp.metrics ¶

    Figures of merit for quantum image processing.

    Reference: docs/tesi.pdf §3.1.6

    mse ¶

    mse(image_a: ndarray, image_b: ndarray) -> float

    Mean squared error between two images.

    Shapes must match. Computed in float64 to avoid overflow on integer images.

    psnr ¶

    psnr(image_a: ndarray, image_b: ndarray, max_intensity: float | None = None) -> float

    Peak signal-to-noise ratio (dB).

    Parameters:

    Name Type Description Default
    image_a ndarray

    Images to compare. Must have the same shape.

    		 required
    image_b ndarray

    Images to compare. Must have the same shape.

    		 required
    max_intensity float | None

    Peak intensity used in the PSNR formula. If None, inferred from the dtype of image_a (255 for uint8, 65535 for uint16, 1.0 for float).

    		 None

    Returns:

    Type Description
    float

    PSNR in decibels; inf if the images are identical.

    total_variation ¶

    total_variation(image: ndarray) -> float

    Isotropic total variation: sum of √(|∇x|² + |∇y|²) over the image.

    Pixels at the boundary use a one-sided difference (replicate-edge padding). Strictly non-negative; equal to 0 only for a constant image.

    transpile_summary ¶

    transpile_summary(qc: QuantumCircuit, basis_gates: list[str] | None = None) -> dict[str, Any]

    Return depth + op counts before and after transpiling to a basis.

    Useful for characterising scalability: rerun across n to see how depth grows.

    Parameters:

    Name Type Description Default
    qc QuantumCircuit

    Circuit to summarise.

    		 required
    basis_gates list[str] | None

    Target basis. Defaults to a typical near-term superconducting basis (u1, u2, u3, cx).

    		 None

    Returns:

    Type Description
    dict with keys: depth, ops, depth_transpiled, ops_transpiled.

    qimp.qft¶

    qimp.qft ¶

    QFT utilities.

    Thin wrappers around qiskit.circuit.library.QFT that work on arbitrary qubit ranges and integrate cleanly into QIMP pipelines.

    apply_qft ¶

    apply_qft(qc: QuantumCircuit, qubits: Sequence[int] | int) -> QuantumCircuit

    Append a (forward) QFT to qc on the specified qubits.

    qubits can be either an int n (interpreted as range(n)) or any sequence of qubit indices. Works for arbitrary n.

    Append an inverse QFT to qc on the specified qubits.

    qimp.config¶

    qimp.config ¶

    Centralized configuration for QIMP.

    ProcessingConfig dataclass ¶

    Runtime configuration shared by encoders, processors, and the simulator manager.

    All qubit counts are user-provided; the library imposes no upper bound beyond what the chosen simulator can hold in memory.

    Attributes:

    Name Type Description
    n_spatial_qubits int

    Number of qubits per spatial axis. Image size is 2^n × 2^n.
    q_intensity_qubits int

    Number of qubits used to encode pixel intensity (NEQR / NCQI).
    m_image_qubits int

    Number of qubits selecting between stacked images (multi-image FRQI).
    base_shots int

    Default measurement shots for ideal/noisy simulations.
    optimization_method str

    scipy.optimize method name for variational pipelines.
    max_iterations int

    Optimizer iteration cap.
    convergence_threshold float

    Stopping tolerance for variational objectives.
    gpu_enabled bool

    Allow the simulator manager to select a GPU backend if available.
    memory_pool_size int

    Number of pre-allocated image buffers in the runtime memory pool.
